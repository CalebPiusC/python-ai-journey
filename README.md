# 🐍 Python AI Journey — 7-Day Beginner Plan

> Goal: go from complete beginner to confident with Python fundamentals in 7 days.

## How this works
- **One topic at a time.** I teach a lesson, then give you **3 exercises**.
- **No answers** unless you ask — you try first, then send me your code and I'll review it.
- When you're ready, say **"next"** or **"day 2"** and we'll move on.
- Run your code with: `python filename.py`

## The 7-Day Plan

| Day | Topic | What you'll learn |
|-----|-------|-------------------|
| **Day 1** | Variables & Data Types | Creating variables, naming rules, `int`, `float`, `str`, `bool`, `type()` |
| **Day 2** | Strings | Creating strings, concatenation, f-strings, string methods, indexing |
| **Day 3** | Conditions | `if`, `elif`, `else`, comparison & logical operators |
| **Day 4** | Lists | Creating lists, indexing, adding/removing items, useful list methods |
| **Day 5** | Dictionaries | Key-value pairs, adding/updating/removing entries, useful dict methods |
| **Day 6** | Loops | `for` loops, `while` loops, `break` & `continue`, looping through lists & dicts |
| **Day 7** | Functions + Mini-Project | Defining functions, parameters, `return`, plus a small project using everything |
